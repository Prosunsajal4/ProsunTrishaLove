# 💕 Prosun & Trisha — Our Love Sanctuary

> *"Every pixel, every animation, and every melody is crafted with pure love from Prosun to his dearest baby Trisha."*

A luxury, interactive romantic web experience celebrating the anniversary of **Prosun & Trisha (P ❤️ T)**.

---

## ✨ Features & Visual Highlights

- 🌹 **Dynamic Love Timers & Metrics**:
  - **Together In Love**: Live counter ticking up Days, Hours, Minutes, and Seconds since **9th July 2025** (when she said YES!).
  - **Next Anniversary Countdown**: Dynamically calculates the upcoming July 10th milestone so it's always accurate and never expires.
  - **Live Relationship Metrics**: Real-time counter of heartbeats together (~40+ million), shared smiles, and days in love.
- 🎨 **Romantic Canvas Universe**:
  - High-performance 60fps HTML5 Canvas with gently drifting rose petals, dreamy stardust, and soft bokeh floating hearts.
  - Interactive tap & click heart burst effects anywhere on screen.
- 🕯️ **Candlelight Dark Mode**:
  - Seamless toggle between Daylight Blush and Candlelight Velvet Midnight with glowing rose accents and persistent state via `localStorage`.
- 💌 **3D Interactive Love Letter**:
  - Realistic 3D envelope with golden wax seal stamped `P & T`.
  - Breaking the seal triggers a chime, confetti shower, and unfolds the vintage parchment love letter with handwritten calligraphy.
- 📸 **Polaroid Memories Album**:
  - Polaroid-style cards with photo tape and organic tilts.
  - Category filtering: *Our Firsts*, *Special Dates*, *Everyday Love*.
  - Full-screen modal lightbox with Prosun's secret thoughts and a *"Send a Kiss 💋"* button.
- 💝 **Interactive Love Quiz 2.0**:
  - 5 heartfelt questions celebrating the milestones of Prosun & Trisha.
  - Live progress bar, Web Audio sound effects, confetti bursts, and an official **Love Master Certificate**.
- ♫ **Audio Synthesizer & Vinyl Turntable**:
  - Global floating audio player dock accessible across all pages.
  - Built-in Web Audio API romantic acoustic synthesizer playing the *Saiyara* love melody (works out-of-the-box with zero external audio dependencies, and seamlessly plays `audio.mp3` if added).
  - Realistic spinning vinyl record with tonearm animation on the song page.
- 📱 **100% Responsive & Touch Safe**:
  - Fully responsive mobile drawer navigation with smooth animations.
  - Touch-device safe cursor detection preventing tap obstructions.

---

## 🛠️ Tech Stack & Architecture

- **Frontend**: Vanilla HTML5, Modern CSS3 (Glassmorphism 2.0, CSS Grid, Custom Properties), Vanilla JavaScript (ES6+).
- **Audio**: Web Audio API (Dual-oscillator acoustic synthesizer with gentle envelopes) + HTML5 Audio fallback.
- **Visual FX**: HTML5 Canvas 2D Context, CSS Keyframe Animations, Web Animations API.
- **Workflows & Hosting**: Vercel & GitHub Actions CI/CD for automated integrity checks and static deployment.

## 🚀 Local Development

To run the project locally on your machine:

```bash
# Using Node.js
npm run dev

# Or with Python 3
python -m http.server 3000
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🧪 Testing & Health Check

Run the automated integrity test script:

```bash
npm test
```

This verifies:
- Complete file presence and sizes
- Internal link validity across all HTML pages
- JavaScript syntax and runtime parsing
- CSS brace balance and selector structure
